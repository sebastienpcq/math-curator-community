# Contribuer à Math Curator Community

Merci de vous intéresser au projet !

## Signaler un problème

Ouvrez une [issue](../../issues/new/choose) en indiquant le navigateur, la version de l'extension, les étapes pour reproduire le problème et le résultat attendu.

## Proposer une amélioration

Décrivez le besoin concret et, si possible, la manière dont l'amélioration aiderait à apprendre les mathématiques sur YouTube.

## Proposer du code

Avant toute modification importante, ouvrez une issue pour discuter de l'idée. Si le code source est disponible dans le dépôt, créez une branche, testez votre modification dans Chrome et ouvrez une pull request expliquant ce qui change.

Ne publiez jamais de clés API, d'identifiants ou de données personnelles.

Ce projet évolue progressivement : les propositions ne pourront pas toutes être intégrées immédiatement.
