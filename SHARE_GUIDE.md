# Partage à une petite communauté

## Phase privée (5 à 15 testeurs)
- Envoyer le ZIP par un espace connu et sûr. Ajouter la procédure `chrome://extensions` du README.
- Leur dire que l’installation en mode développeur est manuelle et réservée au code auquel ils font confiance.
- Collecter : version Chrome, page YouTube concernée, vidéo masquée à tort, capture avec données privées occultées, reproduction, éventuelles erreurs. Ne demander ni mot de passe ni données de compte.
- Après corrections et essais indépendants, préparer les éléments Web Store : description, captures réelles, icône, déclaration de confidentialité, permission et usage unique.

## Phase Chrome Web Store (recommandé pour la suite)
- Créer un compte développeur Chrome Web Store, payer les frais d'inscription uniques.
- Déposer le ZIP via le Developer Dashboard (soumettre pour revue).
- Dans Distribution choisir **Unlisted / Non répertoriée**. Le lien pourra alors être diffusé aux personnes choisies, et partagé par elles : ce n'est pas une barrière d'accès.
- Pour tester avec une liste fermée de comptes, considérer Private/Trusted testers.
- Ne pas prétendre que la qualité pédagogique est vérifiée : le classement est heuristique.

Sources : https://developer.chrome.com/docs/webstore/register/ ; https://developer.chrome.com/docs/webstore/publish/ ; https://developer.chrome.com/docs/extensions/how-to/distribute/
